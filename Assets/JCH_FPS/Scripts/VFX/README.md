## 피해 반경과 연출 크기

폭발탄의 1레벨 피해 반경은 **3.2**(기존 4 × 외형 배율 0.8),
유탄은 **3.25**(기존 5 × 외형 배율 0.65)입니다.
두 연출의 외형 배율은 **1**로 맞췄으므로 화면상 화염/연기 크기는 변경 전과 같습니다.
피해 반경은 각 퍽의 `radius`이며 `VfxConfig`의 배율은 외형만 조절합니다.
불꽃/불씨/연기는 불규칙하게 움직이는 장식이므로 보이는 외곽선이 정확한 피해 경계는 아닙니다.
테스트 씬의 **실제 피해 범위 표시**로 구형 피해 판정의 원과 반원 윤곽선을 확인할 수 있습니다.

## 유탄 비행 / 화염 기둥과 연기

**유탄 비행과 화염 기둥 (Grenade Ammo)**에서 초록 궤적 색, 화염 시간,
전체 연출 시간, **폭발 외형 크기 배율**, **화염 기둥 세로 배율**, 불꽃/불씨,
검은 연기 수/색/크기/상승 높이, 바닥 먼지 수/색/확산 거리를 조절합니다.
모든 항목은 한국어 표시명과 툴팁이 있으며 다음 발사/폭발부터 적용됩니다.
실제 유탄 반경은 `Special_Grenade.asset`의 `radius`이며 VFX 크기는 피해 범위를 바꾸지 않습니다.

비행 궤적은 일반탄/폭발탄과 같은 구현의 초록색 버전입니다. 기존 포물선과 중력,
충돌 시 폭발 및 수명 종료 시 제자리 폭발, 즉시 1회 범위 피해는 유지합니다.
유탄의 기존 구체 폭발은 주석으로 보관했습니다.
착탄은 `VfxService.PlayGrenadeImpact` → `GrenadeImpactVfx`로 재생되며
공통 화염을 세로로 분포시키고 `BlastSmoke.shader`로 검은 연기와 지면 먼지를 만듭니다.
런타임에 `Reference_GrenadeAmmo.jpg`를 읽지 않으므로 참조 폴더의 Git 제외를 유지합니다.

테스트 씬은 현재 작업 중인 **유탄**을 기본 반복 재생합니다. 상단 유탄 탭 →
**VfxConfig 열기** → 수정 → **설정 적용 / 다시 재생** 또는 Space로 확인합니다.
**착탄 화염만 보기**는 비행을 생략합니다. 관찰용 포물선은 느린 2초 시연이며
실제 전투 궤적/속도는 `SpecialProjectile`과 유탄 퍽이 결정합니다.

## 폭발탄 비행 / 화염 폭발

`VfxConfig.asset`의 **폭발탄 비행과 화염 폭발 (Explosive Ammo)**에서
빨간 궤적 색, 폭발 시간/크기, 불꽃 수/색/무늬/흐름, 불씨 수/굵기/길이를 조절합니다.
비행 외형은 일반탄의 `BulletTrailVfx`를 재사용하며, 길이/굵기/머티리얼은
**일반 총알 궤적** 설정을 공유하고 색만 별도로 복사합니다. 일반탄 색은 바꾸지 않습니다.

착탄은 `SpecialProjectile.Explode` → `VfxService.PlayExplosiveImpact` → `ExplosiveImpactVfx`입니다.
참조의 밝은 중심과 노란/주황/빨강 불꽃을 절차적 `FlameBurst.shader`로 표현하며,
불꽃이 팽창하고 위로 흐르면서 바깥 불씨와 함께 사라집니다. `Reference` 이미지에 의존하지 않습니다.
실제 피해는 기존의 즉시 1회 범위 피해이고 지속 화염 피해는 추가하지 않았습니다.
폭발탄과 유탄의 기존 구체 연출은 주석 보관하며 두 탄의 새 착탄 연출은 각각 독립 설정입니다.

로컬 테스트 씬의 상단 **폭발탄** 탭에서 발사→착탄을 반복합니다.
**착탄 화염만 보기**로 비행을 생략하고 **설정 적용 / 다시 재생** 또는 Space로 즉시 재생합니다.
**VfxConfig 열기**는 실제 설정 에셋을 Inspector에서 선택합니다. 반복 중 수정은 다음 재생부터 반영됩니다.
미리보기 이동 속도는 관찰을 위해 느리며 실제 탄의 속도/피해/범위는 `Special_Explosive.asset` 설정입니다.
변경한 폭발 설정은 다음 착탄부터 적용합니다. 항목에 마우스를 올리면 한국어 설명이 표시됩니다.

## 중력탄 비행 / 레벨별 크기

`VfxConfig.asset`의 **Gravity Projectile**에서 중심색/크기, 청록 테두리,
회전 띠 수/폭/길이/속도/색, 꼬리 길이/폭을 조절합니다. 다음 발사부터 적용됩니다.
비행탄 지름은 `Diameter × 실제 중력장 반경 / Reference Radius`입니다.
기본값은 기준 반경 6, 탄 지름 0.7입니다. 구체와 띠, 꼬리 모두 같은 비율로 커집니다.
투사체 충돌 판정은 `projectileRadius`를 사용하며 외형 확대와 별도로 유지됩니다.

`Special_Graviton.asset`의 `radius`와 `gravityRadiusPerLevel`이 실제 전투 범위를 결정합니다.
<!-- 2026-11-23: 요청에 따라 시작 반경과 레벨당 증가량을 조정합니다. -->
현재 기본 반경 3에 레벨당 0.5를 더하므로 레벨 1/2/3은 반경 3/3.5/4입니다.
비행탄 지름은 기존 비례식에 따라 각각 0.35/약 0.408/약 0.467입니다.
증가량 0은 고정 범위입니다. 발사 당시 레벨로 크기와 착탄 범위를 확정하므로
비행 도중 퍽을 강화해도 이미 발사한 탄의 범위는 바뀌지 않습니다.
이 계산은 중력탄에만 적용되며, 공유 퍽 에셋을 런타임에 수정하지 않습니다.

로컬 테스트 씬에서 **중력탄** 탭과 레벨을 선택 후 **설정 적용 / 다시 재생**을 누르면
천천히 날아가는 탄과 도착 후 같은 반경의 중력장을 비교할 수 있습니다.
`Reference/`는 Git 제외이며, 게임 VFX는 참조 PNG에 의존하지 않습니다.

## 중력탄 착탄 / 중력장 VFX

`Resources/VFX/VfxConfig.asset`의 **Gravity Well**에서 입자 수, 굵기 범위,
바깥/안쪽 길이, 흡입 반복 속도, 생성 높이, 휘어짐, 색/밝기,
반구 표면 투명도, 바닥 원/반원 윤곽선 두께와 투명도,
중심 빛 텍스처/크기/높이/맥동, 페이드 시간을 조절합니다.
생성 시 결정되는 입자 수/굵기/속도/높이, 머티리얼/텍스처와 메시/선 값은
다음 착탄 또는 테스트 씬의 Apply settings / replay부터 적용됩니다.

착탄 시 `SpecialProjectile` → `GravityField.Create` → `VfxService.AttachGravityWell`
순서로 재생됩니다. `GravityWellVfx`는 해당 중력장의 자식으로 생성되어
일시정지와 제거 시점을 함께 따릅니다. 실제 반경/유지 시간/흡입 속도/피해는
기존 `PerkData.special`에 있으며, VFX 설정은 전투 판정을 바꾸지 않습니다.
기존 구체 생성/맥동 코드는 `GravityField.cs`에 주석으로 보관했습니다.

로컬 전용 `Assets/LocalVfxLab/VfxPlayground.unity`도 같은 Config와 구현을
사용합니다. 테스트 씬은 Git 제외를 유지하고 본 게임용 VFX/Config는 추적합니다.

<!-- 2026-11-09: 신규 VFX 구성과 기존 코드 수정 지점을 기록합니다. -->

- `VfxService`: 하이어라키에 붙이지 않는 정적 호출 창구입니다.
- `VfxId`: 상황 식별자입니다. 현재 `EnemyHit`만 등록되어 있습니다.
- `VfxConfig`: 상황별 프리팹, 배율, 제거 시간, 표면 오프셋, 회전 보정을 보관합니다.
- `Resources/VFX/VfxConfig.asset`: 최초 호출 때 자동 로드되는 실제 설정입니다.
  기존 `Assets/Art/VFX/HitImpactVFX/00_Prefab/0_Classic/`의
  `VFX_Classic_01.prefab`, `VFX_Classic_02.prefab`을 연결했습니다.
  원본 에셋은 수정하지 않았습니다.

<!-- 2026-11-09: 같은 상황의 복수 후보를 랜덤 재생하도록 확장했습니다. -->
같은 ID의 Entries는 랜덤 후보입니다. 현재 Enemy Hit 두 항목 중 하나가 매 피격마다
각각 50% 확률로 재생됩니다. 같은 이펙트가 연속으로 나올 수 있으며 빈 프리팹은 제외합니다.
크기, 제거 시간, 표면 오프셋, 회전은 후보별로 따로 설정할 수 있습니다.

## 폭발 적 노란 구형 폭발

<!-- 2026-11-23: 폭발 적 공격에만 연결한 노란 화염구와 공통 화염 렌더러 재사용 범위를 기록합니다. -->
`Bomber.Explode`에서 기존 피해 처리 전에 `VfxService.PlayBomberExplosion`을 호출합니다.
폭발 적이 제거되어도 독립 VFX는 끝까지 재생됩니다. 일반 피격으로 죽을 때는 자폭 연출을 추가하지 않습니다.
실제 피해 범위와 대상 판정은 기존 Bomber 코드를 유지합니다.

폭발탄의 `FlameBurst` 재질과 화염 렌더러를 재사용하면서 밝은 노란 중심/노란 화염/
황금색 가장자리를 별도 설정합니다. 구 표면의 균일한 분포와 동시 팽창으로 원형 구체 형태를
유지하며 상승하는 기둥은 만들지 않습니다. 폭발탄과 유탄의 기존 기본 분포는 유지합니다.

`VfxConfig > 폭발 적 노란 구형 폭발`에서 크기, 시간, 불꽃 개수, 세 가지 색과 불씨를 조절합니다.
<!-- 2026-11-23: 피해 반경 0.5와 이미 조절한 이펙트 외형을 독립적으로 유지합니다. -->
실제 피해 반경은 0.5이며, VFX는 프리팹의 `ExplosionVfxRadius`(기존 기준 7.5)에
Config 외형 배율을 곱합니다. 피해 반경을 바꿔도 사용자가 조절한 이펙트 크기는 유지됩니다.
로컬 테스트 씬의 **폭발 적** 모드는 프리팹의 피해 반경과 독립 VFX 기준 반경을 읽어 같은 서비스로
반복 재생하며 하늘색 실제 피해 범위 가이드를 제공합니다. 시연에서 피해는 발생하지 않습니다.

## 플레이어 피격 화면 효과

<!-- 2026-11-23: 약한 흔들림과 실제 HP 50 이하의 피 테두리 연결/조절 위치를 기록합니다. -->
`PlayerMove.Start`에서 `PlayerHitVfx`를 자동 연결합니다. 양수 피해에 기존
`CameraShake`를 위치 세기 0.025, 각도 0.35도, 시간 0.12초로 호출하고, 실제 체력 50 이하에서
화면 가장자리에만 옅은 붉은 얼룩을 표시합니다. 체력 50에서 불투명도 0.14,
체력이 더 낮아지면 최대 0.26까지 증가하며 50을 넘겨 회복하면 사라집니다.
사망 시 숨기고 일시정지 중에는 전환을 멈춥니다.

`VfxConfig.asset > 플레이어 피격과 체력 부족 테두리`에서 흔들림 세기/시간,
시작 체력, 불투명도, 테두리 폭, 색과 전환 속도를 한국어 설명과 함께 조절합니다.
<!-- 2026-11-23: 짧은 피격 흔들림이 생략되던 조건과 대상 카메라 연결 수정 이유를 기록합니다. -->
위치만 움직이는 흔들림은 먼 배경에서 구분하기 어려워 작은 각도를 보완했습니다.
첫 프레임은 경과 시간을 증가시키기 전에 적용해 낮은 FPS에서도 생략되지 않게 했습니다.
플레이어/시연 카메라를 직접 전달하며, 기존 보스 호출은 위치 전용으로 유지합니다.
일시정지/종료/비활성화 때 원래 자세로 복구합니다.
`PlayerBloodEdge.shader`가 가장자리 얼룩을 생성하므로 Git에서 제외한 참조 이미지에
런타임 의존성이 없습니다. 화면 중앙은 투명하며 UI 입력을 가로채지 않습니다.

로컬 테스트 씬의 **플레이어 피격** 모드에서 체력 슬라이더, HP 50/51/회복 버튼,
흔들림 재생 버튼으로 확인합니다. 시연은 실제 플레이어 체력을 변경하지 않습니다.

## 관통탄 금빛 광선

`Reference_PiercingAmmo.png`를 기준으로 금빛 광선, 밝은 별 모양 탄두,
광선 위의 작은 반짝임을 `PiercingProjectileVfx`로 구성했습니다.
<!-- 2026-11-23: 관통탄 꼬리 페이드를 없애고 요청한 굵기 증가량을 기록합니다. -->
광선은 꼬리까지 같은 진하기/굵기를 유지하는 레이저입니다. 중심 굵기는
0.045에서 0.545, 주변 광채는 0.16에서 0.66으로 각각 0.5 늘렸습니다.
`SpecialProjectile.Spawn`에서 연결되며 기존 적 피격 효과와 관통 판정은 유지합니다.
폭발 연출과 범위 피해는 추가하지 않았습니다. 벽 충돌이나 수명 종료 시 탄과 함께 제거됩니다.

`Resources/VFX/VfxConfig.asset > 관통탄 금빛 광선`에서 **광선 길이**, **광선 중심 굵기**,
**주변 광채 굵기**, **탄두 별 크기**, 반짝임 개수/크기/속도와 색을 조절합니다.
각 항목에는 한국어 이름과 툴팁이 있습니다. 수정 후 다시 발사하거나 테스트 씬에서 다시 재생하세요.
실제 충돌 반경과 관통 횟수는 `Special_Piercing.asset`의 `projectileRadius`와
`maxPierceCount` 설정이며 외형 크기와 독립적입니다.

로컬 테스트 씬의 **관통탄** 탭은 같은 VFX로 표적 3개를 통과하는 느린 비행을 반복합니다.
표적 피격은 관찰용 시연이며, 실제 전투 판정 검증은 본 게임에서 진행합니다.

## 현재 연결

`Bullet.OnTriggerEnter`에서 살아 있는 `EnemyBase`에 양수 피해를 적용하기 직전에 호출합니다.
죽이는 공격에도 한 번 재생하며 플레이어, 벽, 이미 죽은 적에는 재생하지 않습니다.
기존 피해 처리와 적 판별 범위는 유지합니다. 근접 공격이나 직접 `TakeDamage` 호출에는
자동 연결되지 않습니다. 자식 콜라이더 피격이 기존에 피해를 주지 않았다면 이 기능도 동일합니다.

트리거 콜라이더는 정확한 접촉 정보를 제공하지 않으므로 `ClosestPoint`와 총알 반대 방향을
사용합니다. 총알이 콜라이더 안으로 들어온 경우 위치는 표면보다 안쪽일 수 있습니다.

## 연출 변경

1. Project 창에서 이 폴더의 `Resources/VFX/VfxConfig.asset`을 선택합니다.
2. Entries의 Enemy Hit 두 항목에서 각각 Prefab, Scale, Lifetime, Surface Offset, Rotation Offset을 조정합니다.
3. 총알로 살아 있는 적을 맞혀 크기와 방향, 재생 종료를 확인합니다.

Config는 플레이 시작 전에 수정합니다. 자동 로드용 Config를 같은 Resources 경로로 중복 생성하지 않습니다.
프리팹은 활성 상태로 저장하고, 전용 연출 스크립트는 해당 프리팹에 붙입니다.
파티클은 자동으로 재생하며, 커스텀 스크립트는 Awake/OnEnable에서 시작하도록 구성합니다.
Lifetime은 가장 긴 하위 파티클의 지연 + 방출 시간 + 입자 수명보다 길게 설정합니다.
반복/비파티클 연출도 Lifetime 뒤에 제거됩니다. 제거 예약은 게임 시간에 따릅니다.

## 다른 곳에서 호출

```csharp
using PesonShooting.VFX;

// 지정 위치에서 재생합니다. rotation의 +Z가 표면 바깥을 향하도록 전달합니다.
VfxService.Play(VfxId.EnemyHit, hitPosition, hitRotation);
```

새 상황은 VfxId 뒤에 값을 추가하고 Config의 Entries에도 같은 ID와 프리팹을 등록합니다.
씬에 매니저를 미리 넣을 필요는 없지만, 재생 중인 VFX 오브젝트는 런타임 하이어라키에 생성됩니다.
현재는 매번 생성/제거하는 방식이며 풀링, 사운드, 카메라 흔들림은 추가하지 않았습니다.
